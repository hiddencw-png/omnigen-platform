# OmniGen Platform
    
    OmniGen is an AI-native code generation platform designed to streamline development workflows. It is built with React, Tailwind CSS, and leverages the power of the Google Gemini API for intelligent code suggestions and generation.
    
    ## Getting Started
    
    To enable the AI-powered features within the OmniGen platform, you will need to add your own Google Gemini API key.
    
    1.  Obtain your Gemini API key from Google AI Studio.
    2.  Open the `index.html` file located in the root of the project.
    3.  Locate the placeholder for the API key and replace it with your actual Gemini API key.
